# OpenSea publishing workflow

Use this workflow for the `emotional-toys` collection.

## Before minting

- Confirm you are signed into the collection-owner account and selected the intended linked wallet.
- Confirm the item has a reviewed metadata file and that its media is final.
- Verify consent, copyright, and the absence of private raw audio or identifying sensor data.
- Decide whether the item is unique or has an intentional edition quantity.
- Keep a copy of the media and metadata outside OpenSea as the archival master.

## Mint

1. Open OpenSea Studio and select **Emotional Toys**.
2. Create the item, upload the approved media, and transcribe the approved title, description, and attributes.
3. Review the wallet, network, supply, creator earnings, and transaction prompt before signing.
4. After confirmation, copy the collection/item URL, network, contract address, and token ID into the item metadata file.

## After minting

- Open the public item page while signed out or in a private browser window.
- Confirm media, description, traits, and creator earnings display as intended.
- Store the transaction URL and archival checksum with the private provenance manifest.
- Do not edit a previously minted item's historical claims to conceal a correction; add a transparent update or successor item instead.

## Verification

OpenSea collection verification is not required for minting or selling. Treat it as a later platform milestone; build trust now with a consistent collection page, official links, clear provenance, and quality work.
